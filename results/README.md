These values are the same for both prompt variants because the control functions
ignore prompt instructions. Each run covers eight scenes, 32 requests, and 192
claim judgments: 87 supported, 49 contradicted, and 56 undetermined under the
current provisional labels. The two constant predictors have zero evidence-update

establish useful reasoning. The uniform score's tied predictions receive no
unique-argmax accuracy credit; random-choice accuracy is a different metric.

## Reproduction

From the repository root:

```sh
python3 -m unittest discover -s tests -v
python3 experiments/reproduce.py
```

The summary contains file hashes for the input dataset, exported requests, and
responses, plus the core implementation hash and actual Python version. Raw
control inputs/outputs are deterministically regenerated in ignored `work/demo/`.
They need not be downloaded from an external dataset or regenerated by an AI.
The frozen fixture file, rather than a generative model, is the source of truth.

Repeated runs on the same Python environment should produce byte-identical
summary files. The checked-in summary was generated with Python 3.14.8. A different
interpreter version changes the recorded version even if all metric values and
artifact hashes match. CI checks tests and repeatability on Python 3.11 and 3.14;
configured CI is not a claim that a remote run has already passed.

Human prose ratings are explicitly marked unscored. The blank annotation and run
manifest templates are not observations. Future empirical results should live
in separate versioned run directories with frozen protocol references, actual
raw synthetic outputs, failure accounting, and a limitations report.

An exploratory author review of fixture labels is preserved in
[the review record](../docs/reviews/2026-10-25-exploratory-label-review.json).
It is not a model result or an independent reliability study.
